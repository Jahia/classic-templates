## Conventions in this documentation

- Field names are written as the editor shows them, in quotes: "Text alternative".
- "Page Builder" is the visual editor; "jContent" is the content and media manager. Both edit the
  same content.
- Every text a visitor reads is content. Nothing is fixed in the code: if a label or a button text
  is wrong, it can be edited, in each language.
